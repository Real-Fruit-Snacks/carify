# Security

carify runs ffmpeg on files you give it and copies the result to a USB stick. It makes no network connections; the installers download one script from this repository over HTTPS.

Report a security problem through GitHub's private vulnerability reporting (Security tab, "Report a vulnerability"), not a public issue. I aim to reply within a week.

Only the latest release is supported.

Problems inside ffmpeg itself belong upstream: https://ffmpeg.org/security.html
